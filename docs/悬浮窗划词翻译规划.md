# 悬浮窗、划词与后续功能规划

## 目标

在第一版文本翻译稳定后，增加跨 App 场景下的悬浮窗、划词和快捷翻译能力。

## 当前状态

- 系统划词入口：已接入 Android `ACTION_PROCESS_TEXT`，可从系统选中文本菜单进入 App。
- 文本分享入口：已接入 Android `ACTION_SEND`，可从其他 App 分享文本进入 App。
- App 内迷你翻译面板：已用于承接系统划词、分享和剪贴板快捷翻译。
- 悬浮球入口：已实现悬浮球、剪贴板桥接和悬浮迷你翻译窗。

## 下一阶段优先级

- 悬浮球截图 / 框选翻译：点击悬浮球后进入屏幕框选模式，截取用户选定区域，OCR 识别后在悬浮卡片内翻译。
- 权限与隐私说明优化：在启用屏幕截图能力前明确说明仅在用户点击后采集一次屏幕区域，不后台录屏，不保存原图。

## 悬浮与划词后续能力

- 悬浮球入口：在其他 App 中快速打开翻译面板。
- 截图框选翻译：面向不可复制文本、网页图片、PDF、聊天截图和游戏/视频字幕等场景。
- 划词翻译：通过无障碍服务读取选中文本或屏幕文本。
- 迷你翻译窗：展示原文、译文、复制按钮和语言方向。
- 后台词句提取：面向网页、聊天、邮件等场景做快速翻译。

## 悬浮球截图 / 框选翻译规划

### 用户流程

1. 用户在任意 App 中点击悬浮球。
2. 悬浮菜单展示两个入口：`剪贴板翻译`、`截图翻译`。
3. 用户选择截图翻译后，系统弹出屏幕捕获授权。
4. 授权后显示全屏半透明框选层。
5. 用户拖拽选择区域，点击确认。
6. App 截取选区图片并调用现有 ML Kit OCR。
7. OCR 成功后复用当前翻译仓库，按用户当前模型设置翻译。
8. 悬浮卡片展示原图小预览、识别文本、译文、复制、朗读、重新框选和关闭。

### MVP 范围

- 只支持用户主动点击悬浮球后的一次截图翻译。
- 只截取用户框选区域，不做后台连续录屏。
- OCR 复用已有中文 + Latin ML Kit 文本识别能力。
- 翻译复用主流程的云端 / 离线模型选择。
- 结果面板复用当前悬浮翻译卡片风格，先保证可用，再做复杂动画。

### 技术方案

- 使用 `MediaProjectionManager.createScreenCaptureIntent()` 请求屏幕捕获授权。
- 增加短生命周期的屏幕捕获前台服务，声明 `mediaProjection` 前台服务类型和对应权限。
- 使用 `MediaProjection.createVirtualDisplay()` 输出到 `ImageReader`。
- 框选层记录选区坐标，拿到屏幕帧后裁剪为 Bitmap。
- 将裁剪 Bitmap 送入 OCR，识别结果进入现有 `TranslationRepository.translate()`。
- 捕获完成后立即停止 `MediaProjection`、关闭 `ImageReader` 并释放前台服务。

### 权限与风险

- 屏幕捕获必须由用户主动授权，每次会话只做一次明确的截取动作。
- Android 14+ 对 `MediaProjection` 会话更严格，不能重复使用同一个授权 token 创建多次虚拟显示。
- 捕获过程中需要前台服务和可见通知，避免系统杀进程，也符合平台限制。
- 需要清楚提示用户：截图内容只用于本次 OCR/翻译，默认不保存原图。
- 不优先采用无障碍读取屏幕文本作为 MVP，因为无障碍权限更敏感，审核和用户信任成本更高。

### 分阶段落地

1. 设计阶段：使用 imagegen 生成截图框选层和悬浮结果卡片设计图。
2. 权限阶段：新增 `MediaProjection` 授权 Activity、前台服务和失败兜底提示。
3. 截图阶段：实现一次性屏幕捕获、选区框选、Bitmap 裁剪和资源释放。
4. OCR 阶段：复用现有图片 OCR 能力，补充旋转、空结果和低清晰度提示。
5. 翻译阶段：复用当前翻译仓库和悬浮卡片，支持复制、朗读、重新框选。
6. 验证阶段：真机验证 Chrome、PDF/图片、聊天截图、横竖屏和权限取消路径。

### 完成标准

- 用户点击悬浮球后可选择截图翻译。
- 首次使用会出现清晰的系统授权和 App 内用途说明。
- 框选区域可以被正确裁剪，OCR 可读取常见中英文文本。
- 识别文本可自动翻译，并在当前 App 外的悬浮卡片中展示。
- 取消授权、取消框选、OCR 为空、翻译失败都有明确提示。
- 捕获完成后停止投屏和前台服务，不保留后台录屏状态。

## 权限与风险

- 悬浮窗需要 `SYSTEM_ALERT_WINDOW` 权限。
- 划词或跨 App 文本读取通常需要无障碍权限。
- 无障碍权限敏感，必须清晰说明用途，不采集非翻译所需内容。
- 不在后台上传用户文本，除非用户明确选择云端翻译。

## 阶段计划

1. 第二阶段先实现系统划词入口、分享入口和 App 内迷你翻译面板。
2. 第三阶段实现悬浮球和悬浮翻译窗。
3. 第四阶段实现悬浮球截图 / 框选翻译。
4. 第五阶段评估无障碍划词能力。
5. 第六阶段补充权限说明、隐私弹窗和用户引导。

## 其他后续功能池

### 翻译体验

- 语言搜索与最近使用语言。
- 翻译风格选择：直译、自然、正式、口语、学术、字幕。
- 长文本分段翻译与分段进度展示。
- 术语表 / 专有名词固定翻译。
- 译文朗读，优先接入 Android TTS。

### 历史与数据

- 历史记录搜索，支持原文和译文关键词。
- 历史收藏 / 常用翻译。
- 生词本 / 句子收藏与复习：从历史记录、词典查询、图片 OCR 和截图翻译结果中一键收藏，后续做复习卡片、朗读和按日期回顾。
- 历史筛选，按语言方向、翻译模式和时间过滤。
- 历史导出，优先支持 TXT / JSON。
- 从历史记录一键重新翻译。

### 模型与供应商

- 供应商连接测试，展示是否可用、延迟和可获取模型数量。
- 自定义供应商删除与复制配置。
- 高级翻译参数：温度、最大输出长度、超时、重试次数。
- 更多本地图标兜底，覆盖 Kimi、GLM、Ollama 等供应商。

### 多模态能力

- 图片 OCR 翻译：相册图片、截图和拍照翻译。
- 悬浮球截图 / 框选翻译：用户主动框选屏幕区域后 OCR 翻译。
- 剪贴板快捷翻译：用户明确触发后读取剪贴板。
- 批量文本翻译：多段文本输入、批量输出与复制。
